# Test data policy

Automated tests run only against unique temporary application-data roots and never use the packaged app's real `LocalState` directory.

`ManagedImageStorageTests` embeds a generated 1 x 1 PNG containing no personal or third-party content. It is used only to exercise byte staging, hashing, immutable promotion and duplicate handling.

`GoldenSamples` contains seven self-authored, deterministic text images generated by `generate-golden-samples.ps1`. Their expected Unicode text, language/script, support boundary, source, and CC0-1.0 fixture license are recorded in `golden-samples.json`. The committed PNGs are generated test content, not private screenshots or vendor benchmark data. Regeneration uses PowerShell 7 so the source script is decoded as UTF-8.

Storage integration tests also create short-lived directory and file symbolic links under unique system-temporary test paths. The links point outside the injected managed root but only to test-owned temporary targets; the assertions verify that reparse-point traversal is rejected and that the external target is preserved. Every fixture removes its links and targets in `finally`/fixture cleanup and never touches user content.

SQLite migration tests create only synthetic schemas in the injected temporary root. They cover verified pre-migration backup, rollback, concurrent initialization, and the race where another initializer creates v1 while an upgrader is waiting to acquire the migration lock; the upgrader must decide backup necessity from the state observed after it obtains the lock.

Analysis tests never download or execute a real model. They use fake image, tensor, and OCR providers to verify manifest/hash validation, detector/CTC post-processing, fallback, staged provenance, lease recovery, idempotent resume, and protection of user-edited fields.

## Remote HTTP and explicit real API tests

Normal Analysis/Integration test runs do not access the public network. The
remote suite injects deterministic handlers and also runs a real loopback fake
HTTP server through the production safe handler. It verifies exact JSON
Schema/JSON Object/prompt-only payloads, all supported reasoning wire formats,
Anthropic thinking/text blocks, bounded responses, endpoint policy, credential
redaction, and that `RemoteOcrText` never opens or serializes an image.

`RealRemoteApiContractTests` is marked `ExplicitRealApiContract` and skipped by
default. Run it only after deliberately supplying a dedicated test credential:

```powershell
.\tests\run-real-remote-contract.ps1
```

The runner defaults to the ignored `.env\myapikey_for_test.txt`, uses synthetic
OCR and `deepseek-v4-flash`, and writes a safe ignored report below
`tests\artifacts\remote-contract`. It reads the secret only in the test process,
does not print it, and clears the environment variables in `finally`. The test
asserts that the image callback count is zero. A real request may be billed and
may already have been processed when cancellation or timeout is observed.

The optional Qwen vision contract uses the separately labelled Qwen credential
from the same ignored file and the pinned built-in licensed cat image:

```powershell
.\tests\run-real-qwen-vision-contract.ps1
```

It sends no library image, OCR, file path, hash, internal ID, or database data.
The test runs the production connection tester and strict parser, reports only
safe sizes/timing/usage/shape metadata, and may be billed by Alibaba Model Studio.

The current real runners intentionally have no image/library argument. They never
opens the product database, enumerates the user's managed library, or binds a
private image to source, fixtures, profiles, snapshots, logs, or release assets.
If a user explicitly authorizes a particular library image for a future
one-off `RemoteVision` contract test, the test must require an explicit path,
copy/re-encode it in a test-only temporary root, upload only the sanitized copy,
avoid persisting the path/content/body, and remove the copy in `finally`. It
must never auto-select or commit that image as a reusable golden sample.
