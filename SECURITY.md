# Security Policy

## Supported versions

Before the first official Release, this project has no supported public binary versions.

After the first official release, security fixes are provided only for the **latest version** on GitHub Releases by default. Any changes to the supported versions will be documented here or in the corresponding Release notes.

## Reporting a vulnerability

Report vulnerabilities privately to **zhdds@protonmail.com**. Do not publicly disclose keys, private images, database content, or complete remote requests/responses. Before a fix or coordinated disclosure, do not publish vulnerability details or exploit code in public Issues, Discussions, logs, or attachments.

Avoid including real user data unrelated to the vulnerability analysis. Where possible, provide:

* The affected version;
* The scope of the vulnerability's impact;
* Necessary reproduction steps or minimal conditions that reproduce the issue;
* Relevant error messages or log excerpts, with API keys, access tokens, personal paths, and other sensitive information removed first;
* Mitigation suggestions, if applicable.

The maintainer will make a best effort to validate the report, assess its impact, and coordinate disclosure. No fixed response or resolution SLA is promised. After a fix, the outcome may be described in Release notes or a security advisory.

## Release authenticity

Obtain release files only from the [official GitHub Releases](https://github.com/dogdreamson555/PicForLater/releases).

The initial `Setup.exe` and application **are not Authenticode code-signed**, so Windows SmartScreen, antivirus software, or organizational security policies may show warnings or block execution. Such a warning alone cannot establish whether a file came from this project.

Public source code, hosting on GitHub, and detached signatures that may be provided for some files **are not equivalent to Windows Authenticode code signing**.

If Windows executables are code-signed in the future, verification instructions will be published here or in the Release notes.
